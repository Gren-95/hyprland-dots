# Keybinds

`Super+F1` opens the live, searchable Keybinds viewer (parses `hyprctl binds`
at runtime — that's always the source of truth). This file is a flat reference
for setup time. Generated by `docs/gen-keybinds.sh` from the live binds;
re-run it after changing `config/hypr/modules/keys.lua`, and `docs/check-keybinds.sh`
flags rows that no longer match.

`$mainMod` = `Super`.

## Apps & system actions

| Key | Action |
|---|---|
| `Super+T` | Open terminal (default app) |
| `Super+L` | Lock screen (hyprlock + album art) |
| `Super+E` | Open file manager (default app) |
| `Super+C` | Color picker (hyprpicker) |
| `Super+B` | Restart all userspace services (`config/scripts/restart.sh`) |
| `Super+Shift+E` | Power menu (Lock / Suspend / Logout / Reboot / Shutdown) |

## Quickshell modals

| Key | Action |
|---|---|
| `Super+R` / `Alt+Space` | App launcher (Spotlight) - `Ctrl+D` hides the highlighted app, `←`/`→` flips to the hidden ones |
| `Super+Shift+D` | Hidden apps - pick one to show again (`↵`) |
| `Super+N` / `Super+D` | Toggle the day panel (calendar + notifications) |
| `Super+V` | Clipboard history |
| `Super+F1` | Keybinds viewer (live, searchable) |
| `Super+M` | System monitor (CPU / RAM / temps / fans / uptime) |
| `Super+A` | Quick actions panel |
| `Super+S` | Audio & Power panel (Sound tab) |
| `Super+W` | Wallpaper deck - hold Super, W deals the next card, release applies |
| `Super+Enter` / `Super+Space` | Apply the card in hand (wallpaper deck) |
| `Super+Esc` | Dismiss the wallpaper deck without applying |
| `Super+Shift+W` | Deal the previous card (wallpaper deck) |
| `Super+Shift+B` | Bluetooth menu (Network modal, BT tab) |
| `Super+Tab` | Workspace overview (cycle next while held) |
| `Super+Shift+Tab` | Workspace overview (cycle previous) |

## Workspaces

| Key | Action |
|---|---|
| `Super+1..9,0` | Switch to workspace N |
| `Super+[` / `Super+]` | Previous / next workspace on current monitor |
| `Super+grave` | Focus next monitor |
| `Super+Shift+1..9,0` | Move window to workspace N |
| `Super+Shift+[` / `Super+Shift+]` | Move window to previous / next workspace on monitor |
| `Super+Shift+grave` | Move current workspace to next monitor |
| `Super+wheel` | Cycle workspace on current monitor |
| `Super+Ctrl+wheel` | Cycle workspace across all monitors |

## Hardware keys

| Key | Action |
|---|---|
| `Lid close` | Lid closed → screen off |
| `Lid open` | Lid opened → screen on |
| `XF86AudioRaiseVolume` / `XF86AudioLowerVolume` | Sink volume ±5% |
| `XF86AudioMute` | Toggle sink mute |
| `XF86AudioMicMute` | Toggle source mute |
| `XF86MonBrightnessUp` / `XF86MonBrightnessDown` | Screen brightness ±5% |
| `XF86KbdBrightnessUp` / `XF86KbdLightOnOff` | Keyboard backlight +1 step (does not wrap) |
| `XF86KbdBrightnessDown` | Keyboard backlight -1 step |
| `Super+Ctrl+K` | Cycle keyboard backlight (off / half / full) |
| `XF86AudioNext` | Next track (playerctl) |
| `XF86AudioPause` / `XF86AudioPlay` | Play / pause (playerctl) |
| `XF86AudioPrev` | Previous track (playerctl) |
| `XF86PowerOff` | Suspend |
